# Excellence-Mapper

## Get Started

Pipeline for Excellence Mapper is included in this repository. The pipeline is a weakly supervised approach to map excellence in research and innovation. The pipeline is designed to extract relations from a news corpus.

The pipeline generates a graph of relations between entities and their corresponding research topics. The graph is available in [this link](https://diegoglezsu.github.io/Excellence-Mapper/pipeline/grafo_silver_interactivo.html).
